# CombatKit

模組化的魔獸世界（正式服）戰鬥插件，資源佔用小。包含：

- **自動換裝**（預設開啟）：依場景（開放世界、探究、地城/M+、Raid、Arena、戰場）自動切換專精、天賦與裝備。
- **顯示屬性**：精簡 HUD 上的即時屬性。
- **顯示距離**：與目標、專注目標、滑鼠指向單位的距離。
- **隊友冷卻** (beta)：競技場隊友的減傷、爆發與控場冷卻，以圖示列顯示在他們的框架旁。
- **額外功能**：進戰鬥提醒、戰鬥中停用右鍵。

每個模組都是獨立的隨選載入插件：沒啟用的完全不載入，不佔記憶體，連它的存檔都不會讀。不帶函式庫，也不帶任何材質或字型檔。

[English](README.md)

## 安裝

從 CurseForge 安裝，或到 [Releases](../../releases) 下載最新的 zip，解壓縮到 `World of Warcraft/_retail_/Interface/AddOns`。解開後會有好幾個資料夾（`CombatKit`、`CombatKit_Loadout`…）：每個模組都是獨立的插件，遊戲才有辦法不載入它。

## 怎麼操作

`/ck` 開啟設定；小地圖的插件收納按鈕、遊戲「選項 > 插件」清單、在 HUD 上按右鍵也都可以。左側列出各模組（自動換裝、顯示屬性、顯示距離、隊友冷卻、額外功能），最下面是**設定**；有多個頁面的模組，頁面是它右側上方的橫向分頁。停用中的模組項目會變暗，點進去可以直接啟用。**設定**底下有三頁：模組、一般（語言、主題色、視窗縮放）、HUD。

啟用立即生效；停用時模組立刻停止運作，但已載入的程式碼要到下次重新載入介面才會釋放，因為遊戲無法卸載程式碼。額外功能底下的小功能共用一個插件，只要其中一項開著才會載入。設定視窗本身也是第一次打開時才載入。

## HUD

一個由模組填內容的小框，自動換裝在上，屬性在下：

```
[圖示] 破滅               就緒
天賦                    M+ AoE
裝備                       PvE
------------------------------
爆擊                     23.4%
加速                     18.0%
```

右鍵：設定。拖曳移動（未鎖定時），`Ctrl` + 滾輪縮放。沒有內容時自動隱藏。在**設定 > HUD** 可以整個關掉，也可以調縮放、背景透明度（可調到完全透明）、邊框、字型、錨點（行數增減時固定不動的角落，預設左上，所以往下、往右長）。字型可選遊戲內建的幾種；如果有其他插件帶了 LibSharedMedia，也會列出它登記的字型。

## 自動換裝

輸入 `/ck`。只有兩項：**PvE** 和 **PvP**。先從上方的大圖示選專精，再在下面選它的天賦配置和裝備套裝；圖示右上角的標記表示那個專精已經設定過。這樣就設定完了。目前是什麼專精，就用那個專精的那一組，所以「用輸出打戰場」和「用補打戰場」只是兩個專精各設一次。欄位下面的「立即切換」會馬上切過去：頁面上選的專精、它的天賦與裝備，不管你人在哪裡。

| | |
|---|---|
| **細分場景**（在 PvE、PvP 頁各自勾選） | PvE 分成開放世界、探究、地城/M+、Raid。PvP 分成 Arena（含單人亂鬥）與戰場/積分戰場（含閃擊戰）。場景預設勾著「沿用 PvE 設定」；取消勾選後，它自己的設定從群組的值複製一份開始。 |
| **自動切專精**（開放世界、探究） | 勾選後用上方的大圖示選專精：進入的當下會切到它，下面的天賦與裝備就是替它設定的那一組。在隊伍中時，不會把你切離隊伍指派給你的職責，被擋下時會在聊天視窗說明；沒有指派職責的隊伍（朋友、NPC 夥伴）不受影響。 |
| **戰爭模式開啟時，開放世界使用 PvP 設定**（在 PvP 頁） | 開著戰爭模式時，開放世界改用 PvP 的設定。 |
| **智慧檢查套裝切換**（選項頁，預設開啟） | 智能分辨當前場景下是否穿戴合適裝備：競技場或戰場沒有戴滿兩個 PvP 飾品時顯示「應切換到 PvP 裝備」，地城、團隊副本還戴著時顯示「應切換到 PvE 裝備」。進入一次戰鬥後就不再顯示；開放世界與探究不判定。PvP 飾品的認定：物品提示裡有「鬥士」套裝。 |

開著「自動切換」（自動換裝分頁 > 選項，預設關閉）時，進入場景（登入也算）套用**一次**，換專精時再套用一次。之後你手動改的不會被改回：HUD 上那一項會分成兩行，一行是目前的，箭頭那行是準備切換的；場景要換專精時，第一行會寫出目標專精。左鍵點一下就切換。它會等戰鬥結束、等你讀條結束，切專精時也會等你站定；被遊戲丟掉的請求會重問，放棄時會告訴你。你自己中斷的施法不會再問：只提示一次，HUD 上會看到還缺什麼。鑰石進行中或 PvP 比賽開打後什麼都不能換，會等到結束。排隊就緒時不會切換，HUD 先顯示該場景要的配置，想現在就換再點它。

這些配置依角色儲存；其他設定都是帳號共用。配置或套裝被刪除後用同名重建，會依名稱重新對上。**除錯**頁可以模擬別的場景，進階裡還能模擬排隊就緒、戰爭模式、隊伍職責或鑰石進行中，在主城就能把流程試一遍；「只模擬」只說明會切什麼。

同一時間只用一個自動換裝的插件：旁邊如果還有別的插件也會自己換天賦或裝備，兩邊會互相改回去。

## 顯示屬性

預設顯示爆擊、加速、精通、臨機應變；可以加上汲取、迴避、移動速度、主屬性、裝等、護甲、閃躲、招架、格擋、裝備耐久。順序和小數位數自己決定；HUD 上的屬性名稱可以改用英文，不管介面是什麼語言。

12.0.5 之後，遊戲在戰鬥中不讓插件讀取你自己的屬性數值（secret 值）：插件不能拿它計算，但可以交給遊戲格式化，所以屬性在戰鬥中照樣更新。例外是需要計算的項目：移動速度與臨機應變的固定加成，戰鬥中顯示最後一次讀到的數值。

## 顯示距離

目標與專注目標旁邊各一個依距離變色的數字，還有一個跟著游標的滑鼠指向距離。敵方單位與非戰鬥中的友方用一組已知射程的物品測量；戰鬥中的友方改用你自己的短射程法術。字型、更新間隔、顯示哪些單位、「5 碼以內不顯示」、解鎖拖曳都在它的設定頁。

## 隊友冷卻

競技場裡每位隊友一列圖示（自己也可以有一列）：他們的減傷技能、彼此互放的外部減傷、爆發技能、打在對手身上的控場，以及他們的種族技能（石像形態、戰爭踐踏之類，依種族判斷，排在那一列最後）。技能可用時圖示是亮的，光環還在時圖示外圍有一圈遊戲內建的動態邊框（預設經典螞蟻線；顯示頁的「高亮樣式」可換細螞蟻線或轉動光帶），顏色依用途而定（減傷綠色，無敵與大型外部減傷黃色，爆發紅色，對手身上的控場紫色，其他藍色），用掉後變暗並跑冷卻轉盤，模組無從得知時顯示「?」（回合中途才加入的隊友、重載介面）。外部減傷與控場記在有可能施放的隊友頭上，你自己放的永遠不算隊友的（之後才觸發的陷阱、圖騰也一樣），當時被昏迷、恐懼或迷惑的隊友也不算；兩人都有可能時，兩邊都顯示估計值並附一個小「?」。每列最前面是 PvP 飾品，資料來自遊戲自己的競技場冷卻資訊。隊友進場時與每回合開始時會 inspect 一次：他選的天賦、PvP 天賦與專精被動對監看技能的冷卻或充能有什麼影響，查一張由遊戲資料檔產生的表；他可選但沒選、或他的專精沒有的技能，會從那一列拿掉；在那之前圖示角落的小點表示用的是職業基礎值。每個新回合全部重置。設定 > 隊友冷卻 > 技能頁依職業列出所有技能，依用途分成減傷、爆發、控場、其他四類，順序和隊友那一列的圖示相同，「種族」底下是各種族的技能；勾分類的框整類開關，每個技能也各有自己的框。冷卻一分鐘以上的技能預設勾選，少數幾個留給你自己勾（種族的爆發技能、群體變形、召喚白虎雪怒、化身：生命之樹、召喚末日守衛）。

它怎麼知道的：在競技場裡其他玩家的光環對插件是機密的。模組請遊戲把每個要監看的 buff（對手身上則是 debuff）畫進模組自己的光環容器槽位，再用一個模組自己的 Cooldown 框架吃那個槽位的持續時間：它跟著 buff 一起顯示與隱藏，模組讀的就只有這一個位元，比遊戲慢一格，別的什麼都不讀。這個設計是新寫的，寫之前先在遊戲裡量過；「透過遊戲畫出來的東西偵測機密光環」這個想法來自 AsIntendedCDs。

## 額外功能

不值得各自成為一個插件的小東西。有設定的功能自己一頁；只有一個開關的集中在**雜項**頁。

- **進戰鬥提醒**：戰鬥開始與結束時，在畫面中央顯示一段文字。兩段文字、字型大小、位置都可以改，也可以讓它往上飄散；「測試」會播放一次。
- **戰鬥中停用右鍵**：戰鬥中游標下有單位時，右鍵只轉視角。屍體也算單位，所以對屍體按右鍵同樣會被擋下；左鍵（開著遊戲的「左鍵互動」時）和互動鍵不受影響。礦、草、寶箱、門不是單位，本來就不受影響。離開戰鬥恢復。

## 外觀與重量

介面是插件自己畫的扁平面板，不用 Blizzard 的視窗外框與按鈕樣式。兩種主題色，潮汐藍與暮紫，在**設定 > 一般**切換；每種都是 `Skin.lua` 裡的一張表，再加一種只要一張表和一個名字。英文與繁體中文也在那裡切換；歡迎補其他語言，每個 `Locales.lua` 都只是一張表。

## 開發

`tests/run_tests.py`（Python + `lupa`）會編譯每個檔案、確認核心的 `.toc` 不會載入任何模組、檢查語言字串有無缺漏與發佈用的中繼資料，並在兩種語言下用 WoW API 替身跑行為測試。`deploy.bat` 把核心和 `Modules/` 底下每個資料夾複製到 AddOns；打包時由 `.pkgmeta` 做同樣的事。推送 `v*` 標籤就會發佈，見 `.github/workflows/release.yml`。`tools/talentdata.py` 透過 wago.tools 從遊戲資料檔重新產生 `Modules/PartyCD/TalentData.lua`（基礎冷卻、充能，以及會改變它們的天賦）；改版後跑一次，並看一下它印出的審核清單；下載的原始資料按 build 存在 `../wago-cache`。
