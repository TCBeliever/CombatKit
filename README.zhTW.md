# CombatKit

**戰鬥小工具，用到哪個開哪個。**

一組輕量的魔獸世界（正式服）戰鬥小工具：依所在場景自動切換天賦與裝備、精簡 HUD 上的即時屬性、與目標和專注目標的距離，以及幾個小功能。每一項各自一個開關，沒開的完全不載入：沒有程式碼、沒有框架，連它的存檔都不會讀進記憶體。

[English](README.md)

| 模組 | 做什麼 | 預設 |
|---|---|---|
| **自動換裝** | 每個專精各設一組 PvE、一組 PvP（天賦配置 + 裝備套裝），進入場景或換專精時自動切換。 | 開 |
| **顯示屬性** | 在 HUD 上顯示你的屬性數值，戰鬥中也會更新。 | 關 |
| **顯示距離** | 與目標、專注目標、滑鼠指向單位的距離。 | 關 |
| **額外功能：進出戰鬥提示** | 進入與脫離戰鬥時顯示一段文字。 | 關 |
| **額外功能：戰鬥中停用右鍵** | 關閉戰鬥中右鍵互動選取目標，避免轉視角時切換目標，離開戰鬥恢復。 | 關 |

## 安裝

從 CurseForge 安裝，或到 [Releases](../../releases) 下載最新的 zip，解壓縮到 `World of Warcraft/_retail_/Interface/AddOns`。解開後會有好幾個資料夾（`CombatKit`、`CombatKit_Loadout`…）：每個模組都是獨立的插件，遊戲才有辦法不載入它。

## 怎麼操作

`/ck` 開啟設定；小地圖的插件收納按鈕、遊戲「選項 > 插件」清單、在 HUD 上按右鍵也都可以。上方每個模組一個分頁（自動換裝、顯示屬性、顯示距離、額外功能），最右邊是**設定**。停用中的模組分頁會變暗，點進去可以直接啟用。**設定**底下有三頁：模組、一般（語言、視窗縮放）、HUD。

啟用立即生效；停用時模組立刻停止運作，但已載入的程式碼要到下次重新載入介面才會釋放，因為遊戲無法卸載程式碼。額外功能底下的小功能共用一個插件，只要其中一項開著才會載入。設定視窗本身也是第一次打開時才載入。

## HUD

一個由模組填內容的小框，自動換裝在上，屬性在下：

```
[圖示] 破滅               就緒
天賦                    M+ AoE
裝備                       PvE
------------------------------
爆擊                     23.4%
加速                     18.0%
```

右鍵：設定。拖曳移動（未鎖定時），`Ctrl` + 滾輪縮放。沒有內容時自動隱藏。在**設定 > HUD** 可以整個關掉，也可以調縮放、背景透明度（可調到完全透明）、邊框、字型。字型可選遊戲內建的幾種；如果有其他插件帶了 LibSharedMedia，也會列出它登記的字型。

## 自動換裝

輸入 `/ck`。只有兩項：**PvE** 和 **PvP**。先從上方的大圖示選專精，再在下面選它的天賦配置和裝備套裝；圖示右上角的標記表示那個專精已經設定過。這樣就設定完了。目前是什麼專精，就用那個專精的那一組，所以「用輸出打戰場」和「用補打戰場」只是兩個專精各設一次。

| | |
|---|---|
| **細分場景**（在 PvE、PvP 頁各自勾選） | PvE 分成開放世界、探究、地城/M+、Raid。PvP 分成 Arena（含單人亂鬥）與戰場/積分戰場（含閃擊戰）。場景預設勾著「沿用 PvE 設定」；取消勾選後，它自己的設定從群組的值複製一份開始。 |
| **自動切專精**（開放世界、探究） | 勾選後用上方的大圖示選專精：進入的當下會切到它，下面的天賦與裝備就是替它設定的那一組。在隊伍中時，不會把你切離隊伍指派給你的職責，被擋下時會在聊天視窗說明；沒有指派職責的隊伍（朋友、NPC 夥伴）不受影響。 |
| **戰爭模式開啟時，開放世界使用 PvP 設定**（在 PvP 頁） | 開著戰爭模式時，開放世界改用 PvP 的設定。 |

進入場景時（登入也算）套用**一次**，換專精時再套用一次。之後你手動改的不會被改回：HUD 對應那行變成琥珀色，左鍵點一下就再套用。它會等戰鬥結束、等你讀條結束，切專精時也會等你站定；被遊戲丟掉的請求會重問，放棄時會告訴你。鑰石進行中或 PvP 比賽開打後什麼都不能換，會等到結束。排隊就緒時不會切換，HUD 先顯示該場景要的配置，想現在就換再點它。

這些配置依角色儲存；其他設定都是帳號共用。配置或套裝被刪除後用同名重建，會依名稱重新對上。**除錯**頁可以模擬別的場景，進階裡還能模擬排隊就緒、戰爭模式、隊伍職責或鑰石進行中，在主城就能把流程試一遍；「只模擬」只說明會切什麼。

同一時間只用一個自動換裝的插件：旁邊如果還有別的插件也會自己換天賦或裝備，兩邊會互相改回去。

## 顯示屬性

預設顯示爆擊、加速、精通、臨機應變；可以加上汲取、迴避、移動速度、主屬性、裝等、護甲、閃躲、招架、格擋、裝備耐久。順序和小數位數自己決定；HUD 上的屬性名稱可以改用英文，不管介面是什麼語言。

12.0.5 之後，遊戲在戰鬥中不讓插件讀取你自己的屬性數值（secret 值）：插件不能拿它計算，但可以交給遊戲格式化，所以屬性在戰鬥中照樣更新。例外是需要計算的項目：移動速度與臨機應變的固定加成，戰鬥中顯示最後一次讀到的數值。

## 顯示距離

目標與專注目標旁邊各一個依距離變色的數字，還有一個跟著游標的滑鼠指向距離。敵方單位與非戰鬥中的友方用一組已知射程的物品測量；戰鬥中的友方改用你自己的短射程法術。字型、更新間隔、顯示哪些單位、「5 碼以內不顯示」、解鎖拖曳都在它的設定頁。

## 額外功能

不值得各自成為一個插件的小東西。有設定的功能自己一頁；只有一個開關的集中在**雜項**頁。

- **進出戰鬥提示**：戰鬥開始與結束時，在畫面中央顯示一段文字。兩段文字、字型大小、位置都可以改；「測試」會播放一次。
- **戰鬥中停用右鍵**：戰鬥中游標下有單位時，右鍵只轉視角。屍體也算單位，所以對屍體按右鍵同樣會被擋下；左鍵（開著遊戲的「左鍵互動」時）和互動鍵不受影響。礦、草、寶箱、門不是單位，本來就不受影響。離開戰鬥恢復。

## 外觀與重量

介面是插件自己畫的扁平面板：不用 Blizzard 的視窗外框與按鈕樣式，不帶函式庫，也不帶任何材質或字型檔。調色盤集中在 `Skin.lua` 的一張表。英文與繁體中文，在**設定 > 一般**切換；歡迎補其他語言，每個 `Locales.lua` 都只是一張表。

## 開發

`tests/run_tests.py`（Python + `lupa`）會編譯每個檔案、確認核心的 `.toc` 不會載入任何模組、檢查語言字串有無缺漏與發佈用的中繼資料，並在兩種語言下用 WoW API 替身跑行為測試。`deploy.bat` 把核心和 `Modules/` 底下每個資料夾複製到 AddOns；打包時由 `.pkgmeta` 做同樣的事。推送 `v*` 標籤就會發佈，見 `.github/workflows/release.yml`。
